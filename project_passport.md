# Паспорт проекта

## 1. Общая информация

**Название:** Каталог русской классики

**Дисциплина:** Инфраструктура и администрирование

**Тип проекта:** REST API

**Версия:** 1.0.0

## 2. Назначение

Приложение предназначено для просмотра каталога произведений русской классической литературы. Оно позволяет получать список книг, искать произведения по идентификатору и выполнять поиск по автору.

## 3. Технологический стек

- Python
- FastAPI
- Uvicorn
- Pydantic
- pytest
- httpx
- Git

## 4. API

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/` | Приветственное сообщение |
| GET | `/health` | Проверка работоспособности |
| GET | `/version` | Версия приложения |
| GET | `/books` | Список произведений |
| GET | `/books/{book_id}` | Произведение по ID |
| GET | `/books/search/{author}` | Поиск по автору |

## 5. Запуск

Активация виртуального окружения:

```bash
source .venv/bin/activate
```

Установка зависимостей:

```bash
python -m pip install -r requirements-dev.txt
```

Запуск приложения:

```bash
python -m uvicorn app_final:app --reload
```

## 6. Проверка

Проверка состояния:

```bash
curl http://127.0.0.1:8000/health
```

Запуск автоматических тестов:

```bash
python -m pytest -v
```

На момент подготовки паспорта локально успешно проходили 5 автоматических тестов.

## 7. Структура проекта

- `app_final.py` — реализация приложения.
- `test_app.py` — автоматические тесты.
- `requirements.txt` — основные зависимости.
- `requirements-dev.txt` — зависимости для разработки.
- `.gitignore` — исключаемые из Git файлы.
- `README.md` — инструкция пользователя.
- `project_passport.md` — паспорт проекта.

## 8. Контроль версий и CI/CD

Исходный код отслеживается с помощью Git. Следующий этап разработки — публикация репозитория на GitHub и настройка GitHub Actions для автоматического запуска тестов.

## 9. Безопасность

Виртуальное окружение и кэш Python исключаются из Git. Секреты и пароли не должны храниться в публичном репозитории.
