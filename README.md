# Каталог русской классики

Итоговый проект по дисциплине «Инфраструктура и администрирование», автор Близнякова С.С.

## 1. Описание проекта

Каталог русской классики — REST API на Python и FastAPI для просмотра произведений русской литературы. Приложение позволяет получить список книг, найти произведение по идентификатору и выполнить поиск по автору.

## 2. Используемые технологии

- Python
- FastAPI
- Uvicorn
- Pydantic
- pytest
- httpx
- Git

## 3. API-маршруты

| Метод | Маршрут | Описание |
|---|---|---|
| GET | `/` | Приветственное сообщение |
| GET | `/health` | Проверка работоспособности приложения |
| GET | `/version` | Информация о версии приложения |
| GET | `/books` | Получение полного каталога |
| GET | `/books/{book_id}` | Получение произведения по ID |
| GET | `/books/search/{author}` | Поиск произведений по автору |

## 4. Требования

- Python 3.14 или совместимая версия Python
- pip

## 5. Установка и запуск

Перейдите в папку проекта и создайте виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установите зависимости для приложения и тестирования:

```bash
python -m pip install -r requirements-dev.txt
```

Запустите сервер:

```bash
python -m uvicorn app_final:app --reload
```

API будет доступен по адресу `http://127.0.0.1:8000`.

Интерактивная документация API: `http://127.0.0.1:8000/docs`.

## 6. Проверка работоспособности

Проверка состояния приложения:

```bash
curl http://127.0.0.1:8000/health
```

Ожидаемый ответ:

```json
{"status":"ok"}
```

Получение каталога:

```bash
curl http://127.0.0.1:8000/books
```

Запуск автоматических тестов:

```bash
python -m pytest -v
```

## 7. Структура проекта

- `app_final.py` — код приложения и API-маршруты.
- `requirements.txt` — основные зависимости.
- `requirements-dev.txt` — зависимости для разработки и тестирования.
- `test_app.py` — автоматические тесты.
- `.gitignore` — исключения для Git.
- `README.md` — документация проекта.

## 8. Назначение

Проект демонстрирует создание REST API, управление зависимостями Python, автоматическое тестирование и использование Git для контроля версий.
## 9. Настройка приложения

Имя приложения задаётся переменной окружения `APP_NAME`. Если переменная не задана, используется значение по умолчанию — `Каталог русской классики`.

Пример для macOS/Linux:

```bash
export APP_NAME="Мой каталог классики"
python -m uvicorn app_final:app --reload
```

Проверить применённую настройку можно запросом к `/version`.

## 10. Автоматическое тестирование и CI/CD

Для автоматического тестирования используется pytest. GitHub Actions запускает тесты при отправке изменений в ветку `main` и при создании pull request в `main`.

Запуск тестов локально:

```bash
python -m pytest -v
```

Результаты автоматических проверок доступны во вкладке **Actions** репозитория GitHub.

## 11. Диагностика

- Если сервер не запускается, проверьте версию Python и установленные зависимости.
- Если порт 8000 занят, остановите другой процесс, использующий этот порт, или выберите другой порт для Uvicorn.
- Если зависимости не найдены, активируйте виртуальное окружение и выполните `python -m pip install -r requirements-dev.txt`.
- Если тесты завершаются с ошибками, изучите сообщения pytest и убедитесь, что запускаете команду из папки проекта.

## 12. Безопасность

- Не добавляйте в Git файлы `.env`, пароли и токены доступа.
- Используйте `.gitignore` для исключения виртуального окружения, кэша и локальных секретов.
- Храните конфигурационные значения в переменных окружения, а не непосредственно в исходном коде.
- Перед публикацией проверяйте репозиторий на наличие секретов.
