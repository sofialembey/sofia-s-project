# Каталог русской классики

Итоговый проект по дисциплине «Инфраструктура и администрирование».

## 1. Описание проекта

**Каталог русской классики** — REST API на Python и FastAPI для просмотра произведений русской литературы.

Приложение позволяет получить список произведений, найти книгу по идентификатору и выполнить поиск по автору. Проект демонстрирует создание API, автоматическое тестирование, управление зависимостями и настройку CI с помощью GitHub Actions.

## 2. Используемые технологии

- Python 3.12
- FastAPI
- Uvicorn
- Pydantic
- pytest
- httpx
- Git и GitHub Actions

## 3. API-маршруты

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/` | Приветственное сообщение |
| GET | `/health` | Проверка работоспособности |
| GET | `/version` | Информация о приложении |
| GET | `/books` | Получение каталога произведений |
| GET | `/books/{book_id}` | Получение произведения по ID |
| GET | `/books/search/{author}` | Поиск произведений по автору |

Интерактивная документация API доступна по адресу `/docs` после запуска приложения.

## 5. Установка

Клонируйте репозиторий и перейдите в папку проекта:

```bash
git clone https://github.com/sofialembey/sofia-s-project.git
cd sofia-s-project
```

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его.

**macOS / Linux:**

```bash
source .venv/bin/activate
```

**Windows PowerShell:**

```powershell
.venv\Scripts\Activate.ps1
```

Установите зависимости:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements-dev.txt
```

## 6. Настройка приложения

Имя приложения задаётся переменной окружения `APP_NAME`. Если переменная не установлена, приложение использует значение по умолчанию, определённое в коде.

В репозитории находится `.env.example` — пример конфигурации. Он не содержит секретов и служит образцом для настройки окружения.

Чтобы задать имя приложения в текущем терминале:

**macOS / Linux:**

```bash
export APP_NAME="Каталог русской классики"
```

**Windows PowerShell:**

```powershell
$env:APP_NAME = "Каталог русской классики"
```

Переменная окружения должна быть задана до запуска приложения. Сам по себе файл `.env.example` не загружает переменные автоматически.

## 7. Запуск приложения

Для обычного запуска без автоматической перезагрузки выполните:

```bash
python -m uvicorn app_final:app
```

Для разработки можно использовать режим автоматической перезагрузки:

```bash
python -m uvicorn app_final:app --reload
```

После запуска:

- API: http://127.0.0.1:8000
- Интерактивная документация: http://127.0.0.1:8000/docs

Остановить сервер можно сочетанием клавиш `Ctrl+C`.

## 8. Проверка работоспособности

Проверка состояния приложения:

```bash
curl http://127.0.0.1:8000/health
```

Ожидаемый результат при успешной проверке:

```json
{"status":"ok"}
```

Проверка информации о версии приложения:

```bash
curl http://127.0.0.1:8000/version
```

Получение каталога:

```bash
curl http://127.0.0.1:8000/books
```

Получение произведения по идентификатору:

```bash
curl http://127.0.0.1:8000/books/1
```

Поиск произведений по автору:

```bash
curl http://127.0.0.1:8000/books/search/Толстой
```

Фактический ответ зависит от данных каталога и реализации соответствующего маршрута.

## 9. Автоматические тесты

Запустите тесты из корневой папки проекта:

```bash
python -m pytest -v
```

Команда запускает автоматические тесты из `test_app.py`. Успешное выполнение означает, что все обнаруженные тесты завершились без ошибок.

## 10. GitHub Actions

GitHub Actions автоматически запускает тесты при:

- отправке изменений в ветку `main`;
- создании pull request в ветку `main`.

После успешного выполнения тестов workflow загружает artifact `fastapi-project` с файлами приложения.

Результаты проверки и доступный artifact можно найти во вкладке **Actions** репозитория.

Ссылка: https://github.com/sofialembey/sofia-s-project/actions

## 11. Диагностика

**Приложение не запускается**

- Проверьте версию Python.
- Убедитесь, что виртуальное окружение активировано.
- Установите зависимости командой `python -m pip install -r requirements-dev.txt`.
- Проверьте сообщения об ошибках в терминале.

**Порт 8000 занят**

Остановите процесс, занимающий порт, или запустите сервер на другом порту:

```bash
python -m uvicorn app_final:app --port 8001
```

**Маршрут `/health` не отвечает**

- Убедитесь, что сервер запущен.
- Проверьте адрес и порт.
- Изучите сообщения в терминале, где запущен Uvicorn.

**Тесты завершаются с ошибками**

- Запускайте команду из корневой папки проекта.
- Проверьте установку зависимостей.
- Изучите подробный вывод команды `python -m pytest -v`.

**Настройка `APP_NAME` не применяется**

Установите переменную окружения в том же терминале до запуска сервера. Проверьте результат через `/version`.
