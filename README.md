# Каталог русской классики

Итоговый проект по дисциплине «Инфраструктура и администрирование», автор Близнякова С.С.

## 1. Описание проекта

Каталог русской классики — REST API на Python и FastAPI для просмотра произведений русской литературы. Приложение позволяет получить список книг, найти произведение по идентификатору и выполнить поиск по автору.

## 2. Используемые технологии

- Python
- FastAPI
- Uvicorn
- Pydantic
- pytest
- httpx
- Git

## 3. API-маршруты

| Метод | Маршрут | Описание |
|---|---|---|
| GET | `/` | Приветственное сообщение |
| GET | `/health` | Проверка работоспособности приложения |
| GET | `/version` | Информация о версии приложения |
| GET | `/books` | Получение полного каталога |
| GET | `/books/{book_id}` | Получение произведения по ID |
| GET | `/books/search/{author}` | Поиск произведений по автору |

## 4. Требования

- Python 3.14 или совместимая версия Python
- pip

## 5. Установка и запуск

Перейдите в папку проекта и создайте виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установите зависимости для приложения и тестирования:

```bash
python -m pip install -r requirements-dev.txt
```

Запустите сервер:

```bash
python -m uvicorn app_final:app --reload
```

API будет доступен по адресу `http://127.0.0.1:8000`.

Интерактивная документация API: `http://127.0.0.1:8000/docs`.

## 6. Проверка работоспособности

Проверка состояния приложения:

```bash
curl http://127.0.0.1:8000/health
```

Ожидаемый ответ:

```json
{"status":"ok"}
```

Получение каталога:

```bash
curl http://127.0.0.1:8000/books
```

Запуск автоматических тестов:

```bash
python -m pytest -v
```

## 7. Структура проекта

- `app_final.py` — код приложения и API-маршруты.
- `requirements.txt` — основные зависимости.
- `requirements-dev.txt` — зависимости для разработки и тестирования.
- `test_app.py` — автоматические тесты.
- `.gitignore` — исключения для Git.
- `README.md` — документация проекта.

## 8. Безопасность

Виртуальное окружение, кэш Python и локальные файлы с секретами не должны попадать в репозиторий. Секретные значения следует хранить в переменных окружения, а не непосредственно в исходном коде.

## 9. Назначение

Проект демонстрирует создание REST API, управление зависимостями Python, автоматическое тестирование и использование Git для контроля версий.
